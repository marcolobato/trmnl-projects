# Debug screenshots

Drop a screenshot here as `preview.png` and it can be measured rather than
looked at — where the blank bands are, how wide, and on which side.

Saving a screenshot on a Mac: press Shift + Command + 4, drag around the
plugin preview, and the file lands on your Desktop. Move it here and rename
it `preview.png`.

Crop as tightly to the plugin as you can. The measurement looks for solid
white rows and columns at the edges, so browser chrome in the shot confuses it.
